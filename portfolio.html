LifeYoda

A daily planning plugin for people running several things at once. It works from the calendar, mail and routines you already keep, so there is no project plan to set up first and nothing linear to maintain. Notion holds the state, which keeps the install short and asks almost nothing of the machine it runs on. The point is to keep you on top of a crowded week and to leave you some peace of mind about it.
